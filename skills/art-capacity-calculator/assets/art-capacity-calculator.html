美术产能与排期计算器

角色 / 场景 / UI 三管线：填数量 / 工时 + 人员名单 → 自动拆工序、算产能、按启动日期排出带日期的计划表

1计算口径

有效工时 = 扣掉会议 / 评审 / 沟通 / 插单后的可排产比例。目标周期用于判断「这批任务能不能在期限内完成」。

2工作日历 周末与节假日不计产能

排期按工作日推进：周末、法定节假日整段不计产能，跨春节 / 国庆会自动右移。调休补班暂不建模，节假日按整天扣。
名称 开始 结束

3标准工时（自动拆解的依据）

这是「一个角色拆成几件事」的基准。动作按「每组」、特效按「每个」计，其余按「件」计。
等级 原画件 模型件 绑定件 动作每组 特效每个 整合件 单角色合计

4任务输入

左三列是你要填的：角色数量、每角色动作组数、每角色特效个数。右边三列自动算。
等级 角色数量 每角色动作组数 每角色特效个数 动作总组数 特效总个数 小计人天

5追加任务 不属于角色的独立件

Boss 专属动作、场景机关特效、时装、武器 —— 填工序、数量、单件人天，自动并进对应工序。不需要就留空。
名称 工序 数量 单件人天 小计

6自动拆解明细

「件数」就是这一批要产出多少资产：几张原画、几个模型、几组动作、几个特效。
工序 件数 单位 平均单件人天 需求人天 周产能 所需周数 目标周期缺口 负荷

1排期表 按启动日期自动出日期

「启动周」可改 —— 就是各工序相对于项目启动日的错峰量。改编它，右边日期和总完工会实时跟着变。
工序 承担组 启动周 工期(周) 结束周 开始日期 结束日期 交付件数 时间轴

3三点估算 给「准不准」一个答案

单件工时不是一个数、是一个区间。固定种子跑 1200 次三角分布模拟：同样的数据永远得到同样的结果，可以拿去开会复核。勾选产能波动后，请假 / 借调 / 离职也会被计入。
工序 乐观 最可能 悲观 为什么是这个区间

4缺口三解 缺的部分怎么补，哪个划算

缺口 = 为达到目标周期还差的人天。这里只算增量成本：在编人力的工资已经发生，不因为加不加人而变化；加人真正多花的是招聘、爬坡损耗和管理。
方案 做法 工期 交付 直接成本 代价 / 风险

5方案对比 保存几版，开会时直接比

先点「保存当前为方案」，再改上面的参数，就会看到「现在这版」跟已保存方案的差距。
# 方案 角色数 总人天 瓶颈 工期(周) 完工日期 可交付 对比当前 操作

6资产台账 逐个角色跟踪，落地后每天在用

按等级自动生成编号；名称、负责人、状态、实际完成日都可以改，改完自动保存。计划完成日跟着排期表走。
编号 名称 等级 当前工序 状态 计划完成 实际完成 负责人 备注

1人员信息 一人一行，产能从这里汇总

姓名可改成真实姓名；「投入%」用于兼职、借调、外包驻场（填 50 就是半个人）。职级系数在下方调。
模型组和绑定组是两个独立资源池：绑定组没人，绑定工序就没有产能；绑定人力来自动作组，把动作组里兼做绑定的人改到绑定组即可。场景人员请到「场景 · 人力产能」里维护。
姓名 职能组 职级 投入% 有效 FTE 备注
批量导入名单（从 Excel 直接粘贴）
每行一个人，格式：姓名 <Tab 或逗号> 职能组 <Tab 或逗号> 职级 <Tab 或逗号> 投入% <Tab 或逗号> 备注（后两项可省）。职能组填角色 / UI 组；场景人员请到「场景 · 人力产能」导入。

2团队产能 不看需求，只看这套人马能产出多少

判断团队是「总量不够」还是「分布失衡」——两者的解法完全不同。
职能组 人数 有效 FTE 周产能(人天) 月产能(人天) 满产月吞吐 本批占用 富余(人天/月)

3周负荷 哪一周爆了、哪一周空了

每格 = 该职能组当周投入的人数。深色 = 有人干活，浅色 = 空闲。最后一行是「全团队在岗人数」。
职能组

2场景标准工时 单场景人天

S = 主城 / 核心区，A = 野外大区，B = 副本 / 小场景。这里按「全价」填，复用折扣在「复用与模块库」里算。
等级 概念 拆分 白模 模型 材质 地编 灯光 优化 单场景合计

3场景任务 填场景数

改场景数会自动增删清单末尾的场景；人天按场景清单的工时汇总，不含模块库一次性投入。
等级 场景数 总需求人天

4复用与模块库 场景成本的最大杠杆

复用资产占比 = 场景里可直接复用既有资产的件数占比；复用件成本系数 = 复用件相对新做件的工时（只做适配 / 改材质）。模块库一次性投入只算一次，摊到所有场景。典型项目 S 30–40%、A 40–50%、B 50–60%，复用件成本 20–30%。
等级 复用资产占比(%) 复用件成本系数(%) 复用后模型(人天/场景) 复用后材质(人天/场景) 每场景节省(人天)

5场景清单 按场景拆，不按档位平均

面积系数 = 面积 ÷ 该档基准面积（S 2000 / A 800 / B 300 m²），限制在 0.6–1.6；模型 / 材质再按「复用与模块库」折减。
编号 名称 等级 面积(m²) 批次 负责人 状态
