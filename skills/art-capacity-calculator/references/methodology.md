# 计算模型与默认值

> 工具里的数字是示例默认值，不是行业标准。真正排期前必须用项目历史数据校准。

## 1. 日历

- 项目从 `startDate` 开始。
- 只有工作日可排；周末和 `holidays` 区间跳过。
- 工期按“工作日 / 5”折算成周，不是自然日 / 7。
- 项目结束日 = 最后任务结束日 + `bufferWeeks` 缓冲。

常用函数：

```text
workdayCount(startIdx, endIdx)  区间内工作日数
consumeForward(startIdx, md, fte)  从某天开始消耗人天，返回结束天
```

## 2. 角色管线

### 工序与资源池

| 工序 | 资源池 |
|---|---|
| 原画 | 原画组 |
| 模型 | 模型组 |
| 绑定 | 绑定组（动作组兼任） |
| 动作 | 动作组 |
| 特效 | 特效组 |
| 整合验收 | 整合组 |

### 需求

```text
角色需求 = 角色数 × 每角色标准工时
动作需求 = 角色数 × 每角色动作组数 × 单组动作工时
特效需求 = 角色数 × 每角色特效个数 × 单个特效工时
额外资产：动作、特效等可另加人天
```

### 默认规模（工具初始值）

- 角色：S 4 / A 8 / B 8，共 20 个
- 动作组数：S 12 / A 5 / B 3
- 特效个数：S 4 / A 3 / B 2
- 总需求约 1165 人天
- 默认建议工期约 27.3 周

### 排期

角色用资源块 + 启动周：

- 原画、模型、绑定、动作、特效、整合分别成块。
- 每块从启动周开始，按该组 FTE 消耗需求。
- 绑定和模型是两个独立块，不能共用人力。

## 3. 场景管线

### 工序与资源池

| 工序 | 责任角色 | 资源池 |
|---|---|---|
| 概念 | 场景原画 | 场景原画组 |
| 组件拆分 | 场景原画 | 场景原画组 |
| 白模 | 场景编辑 | 地编组 |
| 组件模型 | 场景模型 | 场景模型组 |
| 材质 | 场景模型 | 场景模型组 |
| 地编 / 资产替换 | 场景编辑 | 地编组 |
| 灯光 | 灯光 | 地编组 |
| 优化 / 验收 | TA / 优化 | 地编组 |

### 标准工时（人天/场景）

| 档 | 概念 | 拆分 | 白模 | 模型 | 材质 | 地编 | 灯光 | 优化 | 合计 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| S | 12 | 8 | 10 | 45 | 28 | 35 | 14 | 12 | 164 |
| A | 8 | 5 | 6 | 26 | 16 | 20 | 8 | 7 | 96 |
| B | 4 | 3 | 3 | 12 | 8 | 10 | 4 | 3 | 47 |

默认 10 个场景：S 1 / A 3 / B 6，合计 734 人天；加模块库一次性投入后按实际。

### 面积系数

基准面积：

- S：2000 m²
- A：800 m²
- B：300 m²

```text
面积系数 = clamp(场景面积 / 基准面积, 0.6, 1.6)
```

每个场景的每道工序工时 = 档位标准工时 × 面积系数。

### 复用

模型 / 材质按档位复用率和复用成本系数折减：

```text
复用后模型 = 模型标准工时 × (1 - share × (1 - factor))
复用后材质 = 材质标准工时 × (1 - share × (1 - factor))
```

模块库/组件库是一次性投入，只加一次，不参与逐场景随机。

### 排期：逐场景依赖

每个场景按 8 道工序顺序走：

1. 概念完成 → 拆分
2. 拆分完成 → 白模
3. 白模完成 → 模型
4. 模型完成 → 材质
5. 材质完成 → 地编
6. 地编完成 → 灯光
7. 灯光完成 → 优化/验收

同一个资源池内，多个场景的任务按批次、场景顺序排队；按日容量消耗。这样得到的是每个场景每道工序的真实开始 / 结束日期，而不是资源块比例切出来的假日期。

### 复用

复用率只降低视觉 / 切图 / 整合 / 适配，最多降低 50%：

```text
折减系数 = 1 - 复用率 × 0.5
```

UX、动效、验收不因组件复用而降低。

### 排期：逐界面依赖

每个界面按 7 道工序顺序走，三个 UI 资源池排队；组件库作为一次性任务优先占用 UI 视觉组。

## 5. 有效 FTE

```text
有效 FTE = Σ(投入% × 职级系数)
```

职级系数默认：

- 组长 0.6
- 高级 1.0
- 中级 1.0
- 初级 0.9

日产能：

```text
日产能 = 有效 FTE × 效率
```

默认效率 0.85。

角色、场景、UI 可以使用各自独立的职级系数。

## 6. 工期与缺口

```text
项目工期(周) = 最后任务结束天 / 7 + 缓冲周
容量缺口 = Σ max(0, 资源池需求 - 资源池在目标周期内的产能)
工期折算 = 总人天 × (实际工期 - 目标工期) / 实际工期
总缺口 = max(容量缺口, 工期折算)
```

必须区分：

- **容量缺口**：人不够。
- **工期折算**：人够，但依赖/排队/启动太晚导致晚。

“产能够”不代表“没有缺口”；如果总缺口来自晚开工，应写“缺口折算 X 人天来自 Y 周工期，不是容量缺口”。

## 7. 三点估算

每道工序：

```text
乐观 O / 最可能 M / 悲观 P
三角分布采样
```

默认区间：

- 概念：0.8 / 1.0 / 1.6
- 拆分：0.85 / 1.0 / 1.4
- 白模：0.85 / 1.0 / 1.4
- 模型：0.85 / 1.0 / 1.5
- 材质：0.85 / 1.0 / 1.4
- 地编：0.8 / 1.0 / 1.6
- 灯光：0.85 / 1.0 / 1.5
- 优化：0.9 / 1.0 / 1.3

固定种子，结果可复现。输出 P50 / P80 / P90 / 按期概率。

注意：三角分布均值大于最可能值，P50 高于确定性基准是正常的。

## 8. 缺口三解

### A 加人

```text
需补 FTE = 缺口 / (目标工作日 × 效率)
招聘人数 = ceil(需补 FTE)，但至少 1 人
到岗工期 = 目标周期 + 招聘周 + 爬坡月 × (1 - 爬坡期产能) × 周/月
成本 = 招聘人数 × 到岗月数 × 内部月成本
     + 招聘人数 × 招聘成本
     + 招聘人数 × 爬坡月 × 内部月成本 × (1 - 爬坡期产能)
```

**按整人计成本**，不要用小数 FTE 发工资。

### B 外包

```text
外包人天 = 缺口 × (1 + 外包损耗率)
外包成本 = 外包人天 × 外包单价 + 外包人天 × 验收比例 × 内部人天成本
外包工期 = max(目标周期, 外包人天 / 供应商周产能)
```

### C 砍范围

```text
保留比例 = min(1, 目标周期 / 实际工期)
保留数量 = floor(总数 × 保留比例)
```

### D 延期

```text
延期周数 = max(0, 实际工期 - 目标周期)
```

结论必须写清楚推荐方案、代价和不成立条件。

## 10. 执行偏差

```text
工序挣值 = 工序基线人天 × 工序完成%
管线挣值 = Σ 工序挣值
管线完成% = Σ(工序基线人天 × 工序完成%) / Σ工序基线人天
CPI = 管线挣值 / 管线实际人天
剩余 = max(0, 管线基线人天 - 管线挣值)
预测人天 = 实际 + 剩余
预测周 = 基线周 × 预测人天 / 基线人天
偏差 = 预测周 - 基线周
SPI = 完成% / (已过周数 / 基线周)
```

- 工序实际包括返工人天；返工是实际的一部分。
- CPI < 1：实际消耗高于挣值。
- 偏差 > 0：预测晚于基线。
- 场景模块库、UI 组件库作为独立工序行进入基线。
- 这是工序级 earned value-lite，不是逐个资产 / 逐个任务的工时系统。

## 11. 人员可用性

```text
本项目 FTE = 投入% × 职级系数 × (1 - 请假周 / 52)
可再用 FTE = max(0, 100 - 投入% - 其他项目%) × 职级系数 × (1 - 请假周 / 52)
冲突 = 投入% + 其他项目% > 100
```

- 其他项目% 只用于冲突判断，不从本项目扣。
- 请假周会实际扣本项目产能。

## 12. 质量门禁

- 状态：未开始 / 评审中 / 通过 / 带风险通过 / 驳回。
- 记录轮次、反馈数、返工人天、评审人、日期、风险备注。
- 带风险通过必须显式记录风险。
- 返工单独汇总，但执行页的实际人天要把它算进去。

## 13. 资产实际

- 角色 / 场景 / UI 资产台账可以填累计实际人天、返工。
- 资产实际用于复盘和个体验证。
- 管线 CPI 仍使用工序实际，避免资产实际与工序实际重复计算。

## 14. 项目组合

```text
组合周期产能 = 资源池有效 FTE × 效率 × 组合周期工作日
资源池合计需求 = 当前项目需求 + 其他项目需求
缺口 = 合计需求 - 组合周期产能
```

- 当前项目需求自动取角色 / 场景 / UI。
- 其他项目按资源池填总人天，优先级只用于排序展示。
- 当前项目按完整周期计入；组合周期短于项目周期时会高估占用。
- 这是资源总量平衡，不是多项目逐任务排程。

## 15. 供应商管理

```text
订单金额 = 人天 × 单价
验收金额 = 订单金额 × 验收%
供应商负荷 = 订单总人天 / (周产能 × 订单周数)
综合分 = 质量 35% + 准时 25% + 返工 15% + 价格 15% + 配合 10%
```

- 质量 / 配合按 1–5 分。
- 价格分按供应商最高单价归一化；越便宜越高。
- 返工分 = 100 - 返工率。
- 负荷超过 100% 标超负荷。
- 供应商是外部产能视图，不自动回写内部排期。

准入审批：

```text
草稿 → 资料审核 → 样品测试 → 商务审核 → 已准入
```

- 六项资料：营业执照、NDA、作品集、产能证明、报价单、信息安全/IP。
- 资料不齐不能最终准入。
- 驳回后回到驳回状态，可重新提交。

订单拆分：

```text
订单人天 = Σ 场景 / 界面 / 角色资产拆分人天
```

- 拆分对象：场景编号、UI 编号、角色资产编号。
- 拆分工序按管线取对应阶段。
- 拆分合计和订单人天不一致时要提示。
